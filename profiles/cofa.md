## 환경 정책 (cofa 시험 프로필)

이 절은 설치 시 `PROFILE=cofa`(기본값)로 AGENTS.md 끝에 붙는다. 위 범용 규칙보다 우선하는 규정이다. 공식 안내가 이 절과 다르면 공식 안내를 따른다.

### 규정 (공식 안내 근거)

- 제공된 에이전트와 공식 허용 모델만 쓴다. 외부 AI·개인 키·외부 서비스 호출을 쓰지 않는다.
- 문제·데이터·대화·코드·결과물을 외부로 보내지 않는다. Git push를 하지 않는다. 기록은 작업 환경 안의 파일에만 둔다. 공개 하네스·템플릿은 참고용이며 결과물을 통째로 대체하지 않는다.
- 읽기 전용 폴더의 권한을 바꾸지 않는다. 감독·연결 프로세스를 건드리지 않는다. 개인 PC 파일을 반입하지 않는다.
- 화면 확인은 응시자가 플랫폼 미리보기에서 직접 한다. 브라우저·GUI 자동 조작을 하지 않는다.
- 제출물 확정 뒤 후속 서술형에는 AI를 쓰지 않는다.

### 환경 사실

- 요구 문서는 작업 폴더 상위의 `README.md`다. 필수 제출물·기능 요구·계산식·환경(런타임·바인딩·포트)은 거기서 읽는다.
- 플랫폼 미리보기는 앱을 iframe 안에 띄울 수 있다. 응답에 `X-Frame-Options`·CSP `frame-ancestors`를 넣지 않는다. 격리는 인증·권한·경로 제한으로 한다. 서버 바인딩은 README 안내(보통 `0.0.0.0`)를 따른다.
- 시험 과제는 보통 관리자·일반 사용자 인증과 서버 보안 격리를 요구 1번으로 둔다. README에 그 요구가 있으면 범용 규칙의 보안 기본을 전부 적용한다.
- 테스트 러너는 환경에 설치된 것만 믿는다. Python이면 `python3 -m unittest discover -s tests -t .`가 기본이고, pytest는 실제로 도는 것을 확인한 뒤에만.

### 제출 문서 (README가 요구)

- `src/`, `tests/`, `PLAN.md`, `HANDOFF.md`(실행·테스트 방법·테스트 계정 포함), `AI_COLLABORATION.md`(README의 세 물음), 작업 기록(`DECISIONS.md` 권장). README의 목록이 우선한다.
- 개인 운영 원칙(공식 의무 아님): `AI_COLLABORATION.md`는 응시자가 직접 쓴다. 에이전트는 재료(AI 초안을 바꾸게 한 사건, 독립 재계산으로 잡은 것, 담당자 발언으로 정한 규칙)를 한 줄씩 정리만 한다. 제출물에 실제로 있는 사건·숫자·파일·커밋만 쓴다.
