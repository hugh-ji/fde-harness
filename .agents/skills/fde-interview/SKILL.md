# fde-interview

공식 규정과 AGENTS.md의 사용 경계를 먼저 따른다. 시험 중 대상은 플랫폼 내 실무자 에이전트이며 외부 사람에게 연락하지 않는다.

## 목적
실무자의 실제 병목을 해법 전제 없이 파악하고, 실제 요구에 맞는 성공 기준과 범위를 정리하고 확인 상태를 기록한다.

## 절차
1. README·과제 안내에서 이미 알려진 사실을 3줄로 요약하고, **아직 모르는 것**을 목록화한다.
2. 질문을 다음 순서로 5~7개 만든다. 해법 단어(자동화, AI, 앱, 시스템)는 쓰지 않는다.
   - 에피소드: 최근 가장 힘들었던 구체적 사례
   - 워크어라운드: 지금 버티는 방법
   - 정량화: 빈도, 1회 소요, 틀렸을 때 비용
   - 당사자: 만드는 사람, 보는 사람, 책임지는 사람
   - 경계: 바꾸면 안 되는 것, 데이터·보안 제약
3. 답변을 받으면 `AGREEMENT.md` 양식에 채우고, **실제 필수 요구 / 선택 요구 / 제외 사항과 이유**를 제안한다.
4. 실무자에게 보낼 확인 메시지(3~5줄)를 작성한다. 실제 답변과 조건을 원문으로 보존하고, 미회신·반대를 합의 완료로 표시하지 않는다.

## 출력
- 질문 목록(순서대로)
- AGREEMENT.md 초안
- 확인 메시지
