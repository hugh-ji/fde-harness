# fde-interview

## 목적
실무자의 실제 병목을 해법 전제 없이 파악하고, 숫자로 된 성공 기준과 범위를 합의문으로 고정한다.

## 절차
1. README·과제 안내에서 이미 알려진 사실을 3줄로 요약하고, **아직 모르는 것**을 목록화한다.
2. 질문을 다음 순서로 5~7개 만든다. 해법 단어(자동화, AI, 앱, 시스템)는 쓰지 않는다.
   - 에피소드: 최근 가장 힘들었던 구체적 사례
   - 워크어라운드: 지금 버티는 방법
   - 정량화: 빈도, 1회 소요, 틀렸을 때 비용
   - 당사자: 만드는 사람, 보는 사람, 책임지는 사람
   - 경계: 바꾸면 안 되는 것, 데이터·보안 제약
3. 답변을 받으면 `AGREEMENT.md` 양식에 채우고, **만들 것 1개 / 만들지 않을 것 2~3개**를 제안한다.
4. 실무자에게 보낼 확인 메시지(3~5줄)를 작성한다. 끝은 "이대로 맞습니까? 다른 점이 있으면 알려주세요."

## 출력
- 질문 목록(순서대로)
- AGREEMENT.md 초안
- 확인 메시지
