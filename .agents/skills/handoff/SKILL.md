# handoff

## 절차
1. `git log --oneline`, `git status`, 현재 파일 구조를 확인한다.
2. `HANDOFF.md` 양식을 채운다: 현재 상태 / 실행·테스트 명령 / 완료·미완·알려진 버그 / 파일별 역할 / 실무자 합의 요약 / 다음 3단계 / 주의.
3. 사실만 쓴다. 실행하지 않은 것은 "미검증"으로 표기한다.
4. 새 세션에서 이어받을 첫 프롬프트 한 줄을 제안한다. 예: "AGENTS.md와 HANDOFF.md를 읽고 '다음 3단계'의 1번부터 진행. 시작 전 현재 상태를 한 줄로 확인."

## 출력
- 갱신된 HANDOFF.md
- 새 세션용 첫 프롬프트
