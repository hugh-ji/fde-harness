# verify-before-done

## 절차
1. 실행: README의 실행 명령으로 서버/스크립트를 실제로 띄우고 출력을 첨부한다.
2. 테스트: 테스트 명령을 실행하고 출력을 그대로 첨부한다. 실패하면 원인을 로그로 확인한 뒤 고치고 재실행한다.
3. 점검표를 작성한다(항목 / 현재 상태 / 위험 / 수정 필요 여부):
   - 빈 입력, 잘못된 형식, 경계값(0, 음수, 매우 큰 값, 긴 문자열)
   - 중복 실행·재시도 시 상태
   - 에러 메시지에 내부 정보·스택 노출 여부
   - 민감정보 로그·저장 여부
   - 파일 경로·쿼리 등 사용자 입력이 그대로 쓰이는 곳
4. 수정은 사용자 승인 후에만 한다. 수정 뒤 같은 입력으로 재실행 결과를 첨부한다.
5. 마지막에 "미검증" 항목을 명시한다.

## 출력
- 실행 로그, 테스트 로그
- 점검표
- 미검증 목록
